# nem_audition_db

≠ME『名無しのシンデレラ』候補者情報を整理する非公式ファンサイトのスターター版です。

## ファイル

- `index.html` — ページ構造
- `style.css` — デザイン・レスポンシブ表示
- `script.js` — 一覧、並び替え、詳細、ローカル保存
- `data/candidates.json` — 公開用候補者データ（初期状態は空）

## ローカルで確認する

`index.html` を直接開くと、ブラウザのセキュリティ仕様によりJSONの読み込みができない場合があります。PCでPythonが利用できる場合、フォルダ内で次を実行してからブラウザで `http://localhost:8000` を開いてください。

```bash
python -m http.server 8000
```

## 候補者データ形式

`data/candidates.json` に配列形式でデータを追加します。例：

```json
[
  {
    "id": "cand_7f3a9c2d",
    "name": "公式情報を確認して入力",
    "team": "WHITE",
    "imageUrl": "",
    "officialUrl": "",
    "profile": {
      "reading": "",
      "birthDate": "",
      "hometown": "",
      "height": "",
      "bloodType": "",
      "hobbies": "",
      "skills": "",
      "pastAchievements": "",
      "enthusiasm": ""
    },
    "screenings": [],
    "statements": []
  }
]
```

`id` は候補者ごとに固定の内部IDです。候補者番号や名前から推測できる値は使わず、画面には表示しません。候補者名・チーム・公式情報は確認できた内容のみ登録してください。

## 個人用データとプライバシー

- いいね・お気に入り・メモはブラウザの `localStorage` に保存します。
- 個人用データは `candidates.json` に書き込まず、サーバーへ送信するコードもありません。
- 同じ端末・ブラウザを使える人が個人用データを見る可能性があります。
- ブラウザデータの削除などでメモや評価が失われる場合があります。
- 公開リポジトリに秘密情報や個人用メモを絶対に含めないでください。

## 公開前に必ず確認

1. 公式情報との一致、入力漏れ、重複
2. チーム順と登録順
3. スマートフォンとPCでの表示
4. いいね・お気に入り・メモの動作
5. 個人用データが公開データやコミットに含まれていないこと
6. 画像・文章の利用条件と外部リンク
7. 非公式ファンサイトである旨の表示

これは制作開始用の土台であり、32人分のデータは未登録です。公開前に必要なデータと動作の検証を行ってください。
